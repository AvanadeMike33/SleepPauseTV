# YAMNet model attribution

SleepPause TV uses YAMNet, a pretrained audio-event classifier from the
TensorFlow Models project. YAMNet predicts AudioSet classes and is distributed
under the Apache License 2.0 as part of the TensorFlow model ecosystem.

Model download configured by this project:
https://storage.googleapis.com/download.tensorflow.org/models/tflite/task_library/audio_classification/android/lite-model_yamnet_classification_tflite_1.tflite

TensorFlow Models YAMNet documentation:
https://github.com/tensorflow/models/tree/master/research/audioset/yamnet
